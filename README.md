# Markdown Editor

Live split-view markdown editor with syntax highlighting, dark mode and auto-save.

> React · TypeScript · Vite · marked.js · DOMPurify · highlight.js

## Features
- Split view: editor + live preview side by side
- Dark / light mode toggle
- Auto-save to localStorage
- Copy markdown or HTML to clipboard
- Download as .md file
- Word count, char count, line count
- XSS protection with DOMPurify

## Quick start
```bash
npm install && npm run dev
```
